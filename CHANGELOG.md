# Changelog

All notable changes to AVOTREX are listed here, newest first.
Version numbers use MAJOR.MINOR.PATCH:

- **MAJOR**: structural changes (new or renamed variables, a new imputation run that changes many values)
- **MINOR**: species added or removed, taxonomic changes
- **PATCH**: corrections to individual values

## [1.0.0] – 2024-12

- First public release, published alongside Sayol et al. (2024) *Global Ecology and Biogeography* 33(12): e13927.
- 610 extinct bird species. Original data deposited at Dryad: <https://doi.org/10.5061/dryad.zgmsbcckk>.
